# hiveio-api-client

Runtime of Python API clients generated by `hiveio-api-client-generator` (`python/` of this repository): the base
classes generated clients subclass and a minimal HTTP transport calling them. It depends only on `msgspec` - not on
beekeepy, hiveio-api or hiveio-schemas.

- Distribution: `hiveio-api-client`, import package: `hiveio_api_client`.
- Published to the GitLab PyPI registry of the `hive` group
  (`https://gitlab.syncad.com/api/v4/groups/136/-/packages/pypi/simple`) together with the generator, with the same
  version (both are versioned by the tags of this repository).

## Contents

- Generic API-client layer - the same names as `hiveio_api.client` of hive/hive (`AbstractAsyncApi`,
  `AbstractSyncApi`, `AbstractAsyncApiCollection`, `AsyncSendable`, `Callbacks`, `HttpUrl`, `JSONRPCResult`,
  `build_response`, `to_api_builtins`, ...), so hiveio-api can re-export them unchanged.
- `ValueCodec` / `install_value_codec` - how parameters are converted to JSON and results are built. The default codec
  uses `msgspec` (builtins, msgspec structs, dataclasses); a library with its own field types installs its codec once,
  when it is imported:

  ```python
  from hiveio_api_client import ValueCodec, install_value_codec

  install_value_codec(ValueCodec(to_api_builtins=..., value_builder=..., json_default=...))
  ```

  hiveio-api installs its codec this way (Hive assets in symbols of the network, validating field types); `Url` no
  longer derives from `hiveio_api.fields.serializable.Serializable` - hiveio-api registers it
  (`Serializable.register(Url)`) if its encoders need it.
- Transport - `SyncRemoteHandle` / `AsyncRemoteHandle` with `RemoteHandleSettings` (endpoint, timeout, retries), JSON-RPC
  and REST calls, batches of JSON-RPC calls (`handle.batch()`) and callbacks of requests. It uses the standard library
  (`urllib`); asynchronous handles send requests in a worker thread.

## Usage

```python
from hiveio_api_client import AsyncRemoteHandle, HttpUrl, RemoteHandleSettings
from hiveio_balance_api.balance_api_client.balance_api_client import BalanceApi

handle = AsyncRemoteHandle(RemoteHandleSettings(http_endpoint=HttpUrl("https://api.syncad.com")), api=BalanceApi)
delegations = await handle.api.accounts_delegations("gtg")
```

`api` creates the API of the handle for its owner - a generated API class or a collection of them
(`lambda owner: MyCollection(owner)`). Batches of JSON-RPC calls are sent when their context is left:

```python
async with handle.batch() as batch:
    first = await batch.api.first_endpoint(...)
    second = await batch.api.second_endpoint(...)
print(first.some_field, second.other_field)
```

## Errors

Exceptions are in `hiveio_api_client.exceptions`, all derive from `HiveioApiClientError`:

- `CommunicationError` (and `TimeoutExceededError`) - no response; the request is sent again up to
  `RemoteHandleSettings.max_retries` times, `period_between_retries` apart,
- `ResponseError` - the service answered with an error, not retried:
  - `HttpStatusError` - HTTP status 4xx/5xx without a JSON-RPC error,
  - `JsonRpcResponseError` - JSON-RPC `error` instead of `result` (`error`, `request_id`),
  - `InvalidResponseError` - the response is not JSON, does not answer each call of a batch, or the result does not
    match the expected type,
- `ResponseNotReadyError` - a result of a batch accessed before the batch was sent,
- `UnsupportedBatchCallError` - a REST call in a batch.

```bash

poetry run pytest tests/      # generates clients of tests/sample_*_openapi.json and calls a local HTTP server
```
